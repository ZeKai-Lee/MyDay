# MyDay 测试说明

## 测试组成

- `m1.test.mjs` … `m9.test.mjs`：按开发计划里程碑划分的端到端测试。
- 每个文件导出 `{ name, steps }`：
  - `{ url }` 步骤 = 导航/刷新到该地址（相同地址则执行刷新）；
  - `{ js }` 步骤 = 在页面上下文执行的表达式，返回断言数组 `{n:名称, c:是否通过, i:补充信息}`。
- 测试通过**真实页面**运行（真实渲染、真实事件、真实 localStorage），不是模拟。

## 执行方式

测试由 ZCode 会话内的浏览器自动化内核执行（本机无 Node.js，测试运行器内置于自动化内核）：

1. 本地静态服务器（仅回环地址）：`python -m http.server 8377 --bind 127.0.0.1`（在项目根目录）。
2. 浏览器自动化打开 `http://127.0.0.1:8377/MyDay.html`。
3. 运行器读取每个 `tests/*.test.mjs`，逐步执行并汇总断言结果。

> 说明：自动化浏览器无法直接导航 `file://`，因此测试经由 127.0.0.1 访问同一份
> `MyDay.html`。成品本身不依赖服务器——双击 `MyDay.html` 即可使用（无任何外部
> 请求，测试中有专门断言）。双击打开属于手工验收项（PRD 验收第 1、2 条）。

## 手工验收项（自动化覆盖不到的 3 条，共约 3 分钟）

1. **AC1 断网双击**：断开网络 → 双击 `MyDay.html` → 全功能可用
   （测试已证明页面零外部请求，此项主要确认双击打开本身）。
2. **AC2 关浏览器不丢**：录一条数据 → 完全关闭浏览器 → 重新双击打开 → 数据还在
   （测试已在同一存储上验证刷新/重载不丢，此项确认浏览器进程级重启）。
3. **AC4 真实跨天**：把电脑日期改到明天（或次日自然打开）→ 昨日未完成出现在
   「之前未完成」（`?today=` 参数路径已在 m10 自动化验证过同样逻辑）。
