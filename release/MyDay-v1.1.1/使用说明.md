# MyDay 使用说明（v1.1.1 绿色便携版）

MyDay 是一个只属于你自己的工作生活管理工具：今日计划、自媒体、开发工作、咨询工作、健身、饮食、游戏，一个入口全搞定。**不需要安装、不联网、不登录**。

## 怎么打开

双击 `MyDay.html`，用电脑上的 Chrome 或 Edge 浏览器打开即可。整个文件夹可以放在任何位置（桌面、D盘、U盘都行）。

## 数据存在哪里、怎么备份

- 所有数据保存在**这台电脑、这个浏览器**里，不会上传到任何地方。
- 备份：打开 App → 数据与设置 → **导出全部数据**，会得到一个 `MyDay-日期.json` 存档文件。建议每月导出一次，存到 U 盘或网盘。
- ⚠️ 注意：浏览器的"清除浏览数据"会把 MyDay 数据一起清掉，清理前先导出存档；不同浏览器（Chrome/Edge）的数据互不相通。

## 换电脑迁移（三步）

1. **旧电脑**：数据与设置 → 导出全部数据，得到存档 JSON；
2. 把**整个文件夹**（至少含 MyDay.html）和**存档 JSON** 一起拷到新电脑（U盘/网盘均可）；
3. **新电脑**：双击 MyDay.html 打开（首页会出现"从存档导入"引导）→ 数据与设置 → 从存档导入，选刚才的 JSON，数据完整恢复。

也可以把整个文件夹直接放进 U 盘随身带，在任何 Windows/Mac 电脑上双击即用。

## 升级版本

用新版的 `MyDay.html` 直接替换旧文件即可，数据存在浏览器里，不受影响。

## 功能速览

首页总览（今日速览+快速备忘+各模块摘要）｜今日计划（四类归属、未完成顺延）｜自媒体（选题库+发布看板+数据看板图表）｜开发工作（项目/任务/笔记搜索）｜咨询工作（客户/记录/待办一键进今日）｜健身计划（周模板/记录/月历）｜饮食计划（四餐/喝水/速查表/月历）｜游戏娱乐（游戏库/时长统计）｜数据与设置（中英双语、深浅色、备份恢复）。
