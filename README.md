# MyDay · 个人工作生活管理

一个只属于你自己的工作生活管理工具：**免安装、不联网、不登录、数据全部留在本机**。

> 今日计划 ｜ 自媒体发布看板 ｜ 开发工作 ｜ 咨询客户 ｜ 健身打卡 ｜ 饮食记录 ｜ 游戏库 ｜ 数据备份 —— 一个入口全搞定。界面支持中文 / English，浅色 / 深色主题。

## 下载使用

| 版本 | 获取方式 | 打开方式 |
|---|---|---|
| **exe 桌面版**（推荐） | [Releases 页面](https://github.com/ZeKai-Lee/MyDay/releases) 下载 `MyDay-v1.1.1-exe-win64.zip`（约105MB） | 解压后双击 `MyDay.exe`，独立窗口运行 |
| **网页便携版**（超轻量） | 下载 `release/MyDay-v1.1.1-portable.zip`（28KB） | 解压后双击 `MyDay.html`，用 Chrome/Edge 打开 |

系统要求：Windows 10/11 x64。不需要安装任何东西。

## 功能一览

- **首页总览**：今天要做的事、快速备忘、各模块重要摘要，30 秒看清一天
- **今日计划**：按归属（自媒体/开发/咨询/生活）分组，昨天没做完的自动进"顺延区"
- **自媒体**：选题灵感库 → 四列发布看板（想法/准备中/草稿完成/已发布）→ 数据看板图表（播放/点赞/评论）
- **开发工作**：项目、任务清单、笔记与片段（跨项目搜索）
- **咨询工作**：客户名录、咨询记录，跟进事项一键变成今日待办
- **健身计划**：每周模板、训练打卡（动作/组数/次数/重量）、月历视图
- **饮食计划**：三餐加餐记录、喝水打卡、食物热量速查表、月历视图
- **游戏娱乐**：游戏库（在玩/想玩/通关/弃坑）、游玩时长统计
- **数据与设置**：一键导出/导入存档、中英双语、深浅色主题

## 💾 数据备份与迁移到其他电脑（重要）

### 你的数据存在哪里

- **exe 桌面版**：`C:\Users\你的用户名\AppData\Roaming\MyDay`（专属目录，卸载/删除程序文件夹不影响数据）
- **网页便携版**：这台电脑、这个浏览器的本地存储里

所有数据**只存在本机**，应用不联网、不上传任何内容。

### 迁移到另一台电脑（三步）

1. **旧电脑**：打开 MyDay → **数据与设置** → **导出全部数据**，得到存档文件 `MyDay-日期.json`；
2. 把 **MyDay 本体**（exe 版的整个文件夹，或网页版的 MyDay.html）和**存档 JSON** 一起拷到新电脑（U盘 / 网盘均可）；
3. **新电脑**：打开 MyDay（首页会出现"从存档导入"引导）→ **数据与设置** → **从存档导入** → 选择 JSON → 全部数据完整恢复。

### 注意事项

- 建议每月导出一次存档，另存到 U 盘或网盘，防患于未然
- 网页版注意：浏览器"清除浏览数据"会把 MyDay 数据一起清掉；Chrome 和 Edge 的数据互不相通
- exe 版和网页版的数据互相独立，两版之间搬家也用"导出/导入"即可
